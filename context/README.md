# context/ — Derived chat-bridge artifacts (NON-AUTHORITATIVE)

This directory is **derived and non-authoritative.** The eleven `docs/` homes are the sole source of truth for all project facts. On any conflict between files here and the `docs/` homes, **the homes win.** These files exist solely to bridge chat-to-chat context loss and to make uncommitted chat-side decisions *visibly pending* rather than laundered into apparent fact.

| File | Purpose |
|---|---|
| `PROJECT_GUIDE.md` | **START HERE.** One-stop orientation: what the project is, the doc-map (every doc explained), the locked spine, a glossary, and how to plan a blueprint. Stable — changes only when the doc system / workflow changes. |
| `CANONICAL_FACTS.md` | Derived projection (cache) of the eleven homes — current-state facts with `→ home` pointers. Regenerated by CC whenever a run changes any projected fact. **Re-upload to Claude.ai project knowledge after each regeneration** (CLAUDE.md rule 15). |
| `PENDING_CC.md` | Append-only ledger of chat-side deltas not yet reconciled into a home. Read and drain at the start of every blueprint/directive run (CLAUDE.md rule 14). |

**A fresh chat should read `PROJECT_GUIDE.md` then `CANONICAL_FACTS.md` to be fully current.**
