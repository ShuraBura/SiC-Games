## 1. The diagnosed gaps (with data)
**Gap A — biome ↔ climate are DECOUPLED, and the temperature field is impoverished (this IS the deferred CL-1 climate stage).** The `temperature` field is a pure **latitudinal** gradient (row 0 equator 27 °C → row N-1 pole 1 °C; `terrain.py` L665) — it is **NOT seasonal** (a single static annual mean; the only seasonality in the model is a *food*-capacity multiplier `ClimateField.season()`/`a_seas` + the R-46 biome seasonal-*amplitude*, NOT temperature), **NOT elevation-dependent** (no lapse — montane reads WARM), and **NOT biome-consistent** (biome is classified from moisture/npp/elev at L595, never temperature). Consequence (occupied-cell means, R-48 probe): **savanna 11.8 °C (coldest!), montane 15.3 °C (warmest)** — inverted vs Earth. **Required temperature field:** `T(cell, month) = T_latitude(row) − LAPSE·elevation + seas_amp(cell)·seasonal_wave(month)`, with seasonal amplitude larger at high latitude / continental interiors and driven by the SAME insolation signal that already drives the food seasonality (reconcile, don't duplicate). Then **derive biome from T + moisture (Whittaker)** so biome is an OUTCOME of climate, not decoupled from it (causal note: biome follows temperature, not the reverse). This activates the deferred **CL-1** (temperature/humidity, solar-forced) — see DEFERRED_MECHANICS.

**Gap B — the aquatic resource is DISCONNECTED from the agent economy (confirmed 2026-07-03).** The Bird-1997 shore bonus (+1491.5 kcal/hr) lives in `forage_kcal`, but agents forage from `NPPCapacityField`, which is built from `npp_gm2` ALONE (`capacity.py` L42) and NEVER reads `forage_kcal`. Water cells have `npp=0`, so there is ZERO aquatic productivity in the harvest field the agents actually use. That is why `shore%`/`river%` = 0 at occupied cells — NOT because agents sit on land near water, but because coasts/rivers offer them NO extra food, so they never cluster there (verified: the biome patch DOES contain high-`forage_kcal` shore cells; agents ignore them). **So the aquatic FOOD resource is dormant model-wide.** The stage must therefore (i) build an `aquatic_food` field AND (ii) WIRE IT INTO the capacity/harvest field so productive coasts/rivers actually attract + support denser bands — only then can aquatic-based complexity emerge. A morph gate alone is insufficient.

**Q-checks that motivated this stage (supervisor, 2026-07-03):** (Q1) shore%/river%=0 → the disconnect above, NOT geographically correct. (Q2) desert occupied-cell `wateracc` 0.55 highest = a realistic SELECTION effect (desert foragers water-tethered to oases; the desert world is dry overall, 0.2% water, mean land wateracc 0.27); desert `seasonality` 0.54 highest = defensible for CLIMATE (deserts have extreme temp/rain seasonality) but the WRONG variable for storability (no seasonal food glut) — the temp-seasonality vs food-glut-seasonality conflation. (Q3) below.

## 2. The coherent build sequence (full version — Whittaker INCLUDED)
Ordered so each step's PREREQUISITE is already in place and each risky step is followed by a re-validation GATE that isolates its effect. Steps S1–S2 are demographically INERT (temperature is read only by the inert storage-gate + grass_subtype; RT-A) → no gate needed. The two gates sit after the two steps that touch the demographic equilibria (S3 biome relabel, S5 aquatic capacity).

### S1 — The real temperature field: latitude + elevation lapse + seasonal cycle (CL-1) [INERT]
`T(cell,month) = T_lat(row) − LAPSE·elev_m + T_seas_amp(cell)·cos(2π·month/12 − φ)`; `elev_m = elev × reliefAmpM`, `LAPSE = 6.5 °C/km` (verified scale: montane elev ~1550 m → −10 °C, peaks 15→5 °C); `T_seas_amp` rises with latitude + continentality (small tropics/maritime, large high-lat interior), **driven by the SAME insolation/obliquity signal `ClimateField` already uses for the food season** — one physical driver, not two (RT-D). Gives montane cold, tropics warm-aseasonal, interiors strongly seasonal + a real winter. Whittaker (S3) uses the ANNUAL-MEAN of this; the seasonal cycle feeds the salmon-run window + (optional, OFF by default) winter energetics.

### S2 — River temperature by SOURCE (flow-routing) [INERT, but the hard part — Q3 lit]
Lit-confirmed (LITERATURE.md): river T is set by SOURCE — snowmelt/montane headwaters COLD (<15 °C summer even alpine), lowland/pluvial WARM (tracks air), spring/aquifer STABLE; salmon need cold (opt ~16 °C, lethal >21 °C). **RT-B (the crux): agents live in warm VALLEYS, not cold peaks**, so local-air lapse (S1) does NOT cool occupied cells — the salmon signal REQUIRES the river to carry cold water DOWN from montane headwaters. So `T_river(cell) = f(min upstream/headwater elevation)`, computed by routing the EXISTING flow-accumulation (already run for `isRiver`) to carry an upstream-min-elevation per river cell → lapse-adjusted headwater temperature. This is the load-bearing, expensive step (not "cheap Phase 1a"). One-time at generation; zero per-step cost.

### S3 — Whittaker biome-from-climate (re-derive biome from T_annual × moisture) [HIGH BLAST RADIUS] → **GATE 1**
Re-derive `biome` from the S1 annual-mean temperature × moisture (`forestness`/precip proxy) per the Whittaker envelope: hot+wet→tropical forest, hot+seasonal-dry→savanna, hot+arid→desert, temperate+wet→temperate forest, temperate+semiarid→steppe, cold+wet→boreal, cold+dry→tundra, high-relief→montane. So "savanna" is WARM by construction (fixes the inversion at the root; makes the biome→society deliverable's LABELS trustworthy). **What changes:** the per-cell biome label + label-keyed fields (FORAGE_KCAL_TARGETS, GAME_KCAL_TARGETS, GAME_MOBILITY, BIOME_SEASONAL_AMP, grass_subtype). **What does NOT change:** `npp_gm2` (temperature-independent) → capacity + the demographic equilibria run on npp, so they should be stable. **Also required:** re-calibrate the T×moisture cutoffs against the model's actual ranges (avoid degenerate maps), and **rework the world-lottery archetypes to be CLIMATE-parameterized** (a "savanna world" = warm + seasonal-dry, set via latitude/temperature knobs, not moisture alone). **→ GATE 1 (re-validate):** (i) biome-distribution sanity per archetype (no empty/degenerate categories; diverse worlds preserved); (ii) demographic equilibria R-18/19/E.3 status→RS/band/Gini HOLD (expected — capacity is npp-driven); (iii) re-baseline snapshot/regression tests that pin exact world output. STOP + fix here before S4 if any fails.

### S4 — Aquatic-food fishery field (physical; independent of labels) [NEW SIGNAL]
Per-cell `aquatic_food ∈ [0,1]` = dense-storable-aquatic-food density:
- **Anadromous (salmon):** `coldness(T_river) × river-access × sea-connectivity × productivity`; `coldness = clamp((T_lethal−T_river)/(T_lethal−T_opt),0,1)`, T_opt≈16, T_lethal≈21 (lit); access from `isRiver`/`wateracc`; sea-connectivity from `dist`/river-reaches-water (RT-3 proxy on a torus).
- **Shellfish/marine:** `is_shore × npp` (Bird-bonus littoral) — warm-tolerant coastal (Calusa; RT-4).
- `aquatic_food = max(anadromous, shellfish)`. Lit: Ames 1994/Testart 1982, Binford 2001, salmonid-thermal, river-thermal-by-source. Constants PROVISIONAL.

### S5 — Wire aquatic food into the CAPACITY field [HIGH BLAST RADIUS] → **GATE 2**
Add an aquatic-productivity term to `NPPCapacityField.level()` so a rich fishery cell supports a DENSER band. **RT-C (the point + the risk): coastal foragers reach ~8–10× terrestrial density (NW Coast) — so the aquatic term must ALLOW density ABOVE the Tallavaara terrestrial ceiling** (that super-density IS the packing that unlocks stratification). Calibrate the subsidy so coasts are rich-but-bounded (no runaway coast-crowding). **→ GATE 2 (re-validate):** (i) interior (non-aquatic) equilibria UNCHANGED (aquatic term = 0 away from water → bit-exact interior); (ii) coastal bands reach higher density WITHOUT pathological crowding/collapse; (iii) R-18/19/E.3 hold on interior; (iv) agents now CLUSTER on productive coasts/rivers (Gap-B fixed — the dormant resource is live).

### S6 — Morph fires from aquatic-subsidized DENSITY (retire the R-48 heuristic) [THE PAYOFF]
With S5, coastal density crosses **Binford packing (0.091/km²)** → the EXISTING `society_from_character(density, surplus)` fires egalitarian→complex→**stratified** NATURALLY (no heuristic gate). **This is the elegant endpoint:** the R-46/47/48 wateracc/seasonality/npp-floor gates were WORKAROUNDS for the fact that density never reached packing; once aquatic food provides the real super-density, the ORIGINAL packing/surplus morph is correct and the heuristics RETIRE. **And `stratified` becomes reachable for the first time** (currently impossible; needed for the Ibn Khaldun dynastic arc). Validate: cold productive salmon rivers/coasts → complex/stratified; warm tropical (Mbuti forest, Hadza savanna) + interior desert → egalitarian; complexity rare + aquatic-linked (the real pattern).

## 3. Red-team of the ORDERING (why this sequence, where it can break)
- **Order rationale:** S1→S2 (river T needs air T); S1→S3 (Whittaker needs annual-mean T); S2→S4 (fishery needs river T); S3→S4 (fishery calibrated on the FINAL biome map, and GATE 1 clears before adding S4's productivity); S4→S5 (wire the field once it exists); S5→S6 (morph fires from the subsidized density). Gates ONLY after S3 and S5 — the two demographic-touching steps — because S1/S2/S4 are inert until wired.
- **RT-A [confirmed]:** temperature is demographically inert (only the inert storage-gate + grass_subtype read it) → S1/S2 need no gate; but also means they're unobservable until S4/S5 — don't "validate S1 in isolation."
- **RT-B [confirmed, HIGH]:** the crux is S2 river-routing, not the cheap S1 lapse (agents live in warm valleys). If routing is mis-proxied, the salmon signal misfires → the whole aquatic-complexity result fails. Mitigation: validate T_river distribution (montane-fed rivers cold, lowland warm) BEFORE S4.
- **RT-C [HIGH]:** S5 must exceed the Tallavaara ceiling on aquatic cells (that's the mechanism) — GATE 2 must confirm interior bit-exactness (aquatic term 0 inland) AND no coastal runaway.
- **RT-E [circular validation]:** we must NOT tune S4/S5/S6 constants to reproduce a pre-assumed biome→society table. Independent check: does complexity land on COLD PRODUCTIVE COASTS/RIVERS (the real NW-Coast pattern) *without* reference to biome labels? If yes, it's mechanism, not curve-fit.
- **RT-F [Whittaker blast radius, MED — downgraded]:** smaller than first feared because `npp_gm2`/capacity are label-independent → demographic equilibria stable; the real cost is classifier re-calibration + world-lottery archetype rework + regression re-baselining (bounded, GATE 1 catches breakage).
- **RT-G [ROI]:** resolved — compute is one-time/generation (runtime unaffected); the result is NEEDED (aquatic super-density is the forager route to packing→stratification→dynastic cycle, not a savanna cosmetic). Whittaker included because we're building the temperature field anyway and the deliverable needs coherent labels.
- **RT-D [two seasonalities]:** S1 temperature-season must share the insolation driver with the food-season — one signal, or they double-count.
- **RT-H [new — gate sequencing]:** if GATE 1 (biome) and GATE 2 (aquatic) were merged, a failure couldn't be attributed. Keep them SEPARATE so any equilibrium shift is pinned to biome-relabel vs aquatic-subsidy.
