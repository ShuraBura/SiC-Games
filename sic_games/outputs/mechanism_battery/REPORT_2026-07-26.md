| 4 | **A regime that could not fire the mechanisms** | 120 steps, 300 agents, population *declining* 300→213, **max cell occupancy 5, zero settlements ever formed**. Settlement-gated mechanisms were audited in a world with no settlements |

**Cost on the record.** R-104 Phase 2 ("does circumscription wake the goods axis?") ran with

### 1.4 CRASH — the cred ablation could not be run at all

`enable_cred_status=False` raised `ZeroDivisionError` at `phase1_model.py:3800`:

```python
ratio = top_status / (mean_status + 1e-9)   # ≥1; 1 = no distinct leader
leader_strength = 1.0 - 1.0 / ratio         # <- ratio is exactly 0.0 when all cred is 0
```

The `1e-9` guards the ratio's *denominator* but not the ratio when it is itself a divisor. With status off,
every `cred` is 0 ⇒ `top_status` 0 ⇒ `ratio` 0.0 ⇒ crash on the first band evaluation.

**Why it matters more than a crash:** this is the *control* you would run to ask "how much of any status result
comes from status at all?" It has never been runnable. Every claim that would have been checked against it went
unchecked.

**Fixed** — zero status spread means no distinct leader, i.e. strength 0.0, which is also the `ratio → 1` limit.
Bit-exact wherever any cred is non-zero, so every existing result is untouched. Verified: the ablation now runs
(pop 693 @ 200 steps) **and differs from baseline**, so the control has power. Regression pinned in
`tests/test_leader_strength_zero_status.py` (3 tests: the world runs, the ablation actually ablates, and the
formula is defined at zero spread).

## 8. Battery 5 — the engineered world set  *(status: COMPLETE)*

`battery5_worldset.py`. Tests the SYSTEM rather than mechanisms, with the headline as an **ordering** — which
cannot be hit by tuning one knob. The spine is **T-7** (Smith & Codding 2021, n=89, `[VERIFIED]`), which
TARGETS.md states as a requirement: *"the model must reproduce the ORDERING, not just the existence of
stratification"* — resource **structure** 0.37 vs NPP **productivity** 0.04.

- **Axis P (productivity, structure held constant):** flat-boreal → flat-temperate → flat-tropical.
- **Axis S (structure, productivity ~constant):** flat (diffuse) → hilly (patchy) → coastal (patchy + storable)
  → coastal with defensibility ablated (T-7's ownership term, 0.13).

**Health verdict:** `range(hierarchy | axis S)` must exceed `range(hierarchy | axis P)`. If productivity moves
hierarchy more than structure does, the setup contradicts its own anchor.

Scored off the same runs against documented targets: band ≈ 25, settlement median 50–150 (Bar-Yosef),
connubium ≈ 475 (Wobst), `lineage_size_gini` 0.51–0.68 (BHM), `lin_top_share` ≈ 0.16 (T-9), `ascribed_frac`
vs EA true-elite 3.6–7.8%. **%stratified is deliberately NOT scored as an absolute** — R-105 retired that
number; it is used only as a *relative* quantity between arms, which is what T-7 asks for and what survives the
seed variance.

7 arms × 2 seeds × 3000 steps, run on the **resuscitated** stack. Each arm checkpoints and completed arms are
skipped, so a restart pauses it rather than losing it — re-run the same command to continue.
