§5 — Feasibility Verdict

1. Grid scaling: Runtime scales as O(grid^3.88) based on B0/B1/B3 comparison.

2. N scaling: Insufficient data for N scaling fit.

3. Bottleneck: The dominant cost at current scale (B0) is joint-task at 89% of step time.

4. Feasibility boundary: Configurations feasible for LHS-scale work (500 steps < 5 min): B0. Configurations requiring optimisation: B1.

Action required before Stage 5.x scale-up: JointTaskManager.process_step() accounts for 89% of step time at B0. It iterates over every candidate cell × every agent — O(W×H×N) per step. At constant density N ∝ W×H, this is O(grid²×N) = O(grid³), measured grid exponent 3.884.

Fix (before Stage 5.x): In joint_task.py JointTaskManager.process_step(), replace the full agent scan per candidate cell with a spatial hash (cell → agents at distance d=1). At d=1, each candidate cell only needs to check the 9 adjacent cells — O(1) per cell regardless of N, reducing JT to O(W×H) per step. Expected speedup at B1 scale: >10×.
