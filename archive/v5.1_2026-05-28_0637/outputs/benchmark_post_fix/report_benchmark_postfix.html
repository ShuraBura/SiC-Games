§0 — Fix Summary

File changed: src/sic_games/joint_task.py — JointTaskManager.process_step() only. No other diffs. Config schema, YAML files, and all other model code unchanged.

Algorithm change: The O(W×H×N) inner loop (for each candidate cell: scan all N agents) was replaced with a spatial-hash lookup: build a pos→agent dict in O(N), then for each candidate cell look up only the (2d+1)² = 5 neighbouring positions (d=1, Euclidean). Total cost per step: O(N + W×H).

Test suite: 193 prior tests + 5 new tests = 198 tests, all green. New tests: test_spatial_hash_finds_adjacent, test_spatial_hash_misses_distant, test_spatial_hash_toroidal_wrap, test_no_double_participation, test_task_outcomes_unchanged.
